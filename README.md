# Showdown Entry Filler

https://sku999.github.io/showdown-filler/

Fills reserved DraftKings NHL Showdown entries with Sim Savant's Top 1% rows 1–N.

1. Export the lineup CSV from Sim Savant (after goalies are confirmed).
2. Download DKEntries.csv from DraftKings (My Contests → Upcoming → Edit Entries → Download).
3. Open the page, add both files, tap **Save DKEntries upload**.
4. Upload that file on DraftKings (Edit Entries → Upload).

Everything runs in your browser; no files are uploaded anywhere.
Checks: Top 1% column present, players match the DraftKings slate, salary cap, ties at the cutoff.
